Automated Stroke Prediction Using Machine Learning
An Explainable and Exploratory Study With a Web Application for Early Intervention

Project Overview

This project focuses on early stroke prediction using Machine Learning and Explainable AI techniques. The system analyzes healthcare data to predict whether a patient is likely to suffer from a stroke. The project also provides feature importance analysis using SHAP Explainable AI, helping doctors understand which medical features contribute most to prediction.

Features

• Healthcare dataset preprocessing
• Missing value handling
• SMOTE for imbalance data handling
• Feature selection using CHI2 algorithm
• Multiple Machine Learning algorithms
• Explainable AI using SHAP
• Comparison graph generation
• Stroke prediction from test data

Algorithms Used

• Random Forest
• Logistic Regression
• SVM
• KNN
• Naive Bayes
• XGBoost
• CatBoost

Best Accuracy

• Random Forest — 95%
• CatBoost — 95%

Dataset

Stroke Prediction Dataset from Kaggle containing:

• Age
• Gender
• BMI
• Smoking Status
• Glucose Level
• Hypertension
• Heart Disease
• Stroke Label

Technologies Used

• Python
• Scikit-learn
• Pandas
• NumPy
• Matplotlib
• SHAP
• XGBoost
• CatBoost

Project Workflow

• Upload healthcare dataset
• Preprocess dataset
• Train Machine Learning models
• Compare algorithm performance
• Predict stroke from test data
• Analyze important features using SHAP

Conclusion

The project demonstrates how Machine Learning and Explainable AI can improve early stroke prediction and assist healthcare professionals in medical decision-making. Random Forest and CatBoost achieved the highest prediction accuracy of 95%.
